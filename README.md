# Dansk Lyng

Bilingual (Traditional Chinese + English) brand site for **Dansk Lyng** — Danish heather honey from West Jutland.

TanStack Start (file-based routes, SSR) · React 19 · Vite 8 · Tailwind v4.

Public URLs are language-prefixed:

- `/zh/...` Traditional Chinese (default, `x-default`)
- `/en/...` English

Unprefixed URLs (`/about`, `/products/lyng`, …) redirect to the same path under `/zh` or `/en`. SSR language comes from the URL, not `localStorage`. The language toggle still remembers a preference locally and updates the path.

## Production origin

Canonical, Open Graph, hreflang, sitemap and robots URLs need an absolute origin. Set this at launch — do not commit a `.env` file:

```bash
VITE_SITE_ORIGIN=https://dansklyng.com
```

See `.env.example`. Until this is set, canonical and sitemap entries are path-only and are not valid for search engines.

Confirm `https://dansklyng.com` before enabling it in production.

## Run locally

```bash
git clone https://github.com/teadub11-hub/dansklyng.git
cd dansklyng
npm install
npm run dev
```

Dev server: `http://0.0.0.0:8080` (port is fixed in `vite.config.ts`).

```bash
npm run typecheck
npm run build
npm run preview   # 127.0.0.1:8081
```

## Notes for the next developer

- **Photography is placeholder.** Jars, heath, hives and the hero video are generated stand-ins. Swap files in `public/images/` and `public/video/` using the same filenames, or update the paths in `content.ts` / routes. Rights must be confirmed before production photography goes live.
- **No live CMS / commerce.** Copy is in source. The trade enquiry opens a `mailto:` to `hej@dansklyng.com` and must not say a message was received. Subscribe has no input field until a list is connected.
- **No public trade sheet.** MOQ, exclusivity, market availability, case pack, pallet, deposits, filling certificates and laboratory reports stay off the public site. Detailed commercial terms belong in a private conversation.
- Auth, PGLite, multiplayer and Grok PWA plugins come from the original scaffold. The brand site does not use accounts. Leave them unless you are deploying on that stack — see `DECISIONS.md`.
- `src/routeTree.gen.ts` is generated by TanStack Router — do not hand-edit.

## Stack extras (scaffold)
