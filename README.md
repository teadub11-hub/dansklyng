# Dansk Lyng

Bilingual (Traditional Chinese + English) brand site for **Dansk Lyng** — Danish heather honey from West Jutland.

TanStack Start (file-based routes, SSR) · React 19 · Vite 8 · Tailwind v4.

Default language is Traditional Chinese. Language toggle persists in `localStorage`.

Private repo: [github.com/teadub11-hub/dansklyng](https://github.com/teadub11-hub/dansklyng)

## Run locally

```bash
git clone https://github.com/teadub11-hub/dansklyng.git
cd dansklyng
npm install
npm run dev
```

Dev server: `http://0.0.0.0:8080` (port is fixed in `vite.config.ts`).

```bash
npm run typecheck
npm run build
npm run preview   # 127.0.0.1:8081
```

## Where to edit

| What | File |
|---|---|
| Product copy, journal articles, aroma notes | `src/lib/content.ts` |
| UI strings (zh / en, keep keys in parity) | `src/lib/i18n.tsx` |
| Pages | `src/routes/*.tsx` |
| Header / footer / CTAs | `src/components/site-shell.tsx` |
| Lyng aroma map | `src/components/aroma-map.tsx` |
| Theme tokens | `src/styles.css` |
| Images | `public/images/` |
| Hero video | `public/video/hero-heath.mp4` |
| Favicon / OG | `public/favicon.svg`, `public/og.jpg` |

Routes (file-based):

```
/                  home
/products          catalog
/products/:slug    lyng | blomster | sensommer | skov
/about             brand story
/journal           notes
/journal/:slug
/partner           partnerships
/partner/apply     enquiry form
/faq /contact /privacy /terms /cookies
```

## Notes for the next developer

- **Photography is placeholder.** Jars, heath, hives and the hero video are generated stand-ins. Swap files in `public/images/` and `public/video/` using the same filenames, or update the paths in `content.ts` / routes.
- **No live CMS / commerce.** Copy is in source. The enquiry form stores a draft in `localStorage` and does not send email until a backend is wired.
- Auth, PGLite and Grok PWA plugins come from the original scaffold. The brand site does not use accounts. Leave them unless you are deploying on that stack.
- `src/routeTree.gen.ts` is generated by TanStack Router — do not hand-edit.

## Stack extras (scaffold)

`vite.config.ts` loads `scripts/grok-pwa-plugin.mjs`, `scripts/app-env-plugin.mjs`, and optional PGLite bootstrap if `migrations/` has SQL. Production build uses Nitro (`preset: "vercel"`) with `server/`.
